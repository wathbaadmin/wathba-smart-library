# دليل النسخ الاحتياطي والاستعادة | Wathba Smart Library

## 1. استراتيجية النسخ الاحتياطي لقاعدة بيانات Supabase / PostgreSQL

لحماية بيانات مكتبة وثبة الذكية وضمان استمرارية العمليات، يتم تطبيق خطة نسخ احتياطي ثلاثية المستويات:

### المستوى الأول: النسخ الاحتياطي التلقائي السحابي (Supabase Automated Backups)
- تفعيل النسخ الاحتياطي التلقائي اليومي مع ميزة **Point-in-Time Recovery (PITR)** في مشروع Supabase.
- الاحتفاظ بنسخ الاسترجاع لآخر 7 إلى 30 يوماً.

### المستوى الثاني: النسخ الاحتياطي اليومي عبر سطر الأوامر (pg_dump)
يمكن تشغيل أمر النسخ الاحتياطي التالي يومياً وتخزينه في مسار آمن:

```bash
# أخذ نسخة احتياطية كاملة من قاعدة بيانات مكتبة وثبة
pg_dump "postgresql://postgres:[YOUR-PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres" \
  --format=custom \
  --no-owner \
  --no-privileges \
  --file="wathba_backup_$(date +%Y%m%d_%H%M%S).dump"
```

### المستوى الثالث: تصدير واستيراد البيانات كملفات JSON و Excel من لوحة الإدارة
- توفر المنصة زراً مباشراً في **لوحة الإدارة -> الإعدادات -> النسخ الاحتياطي والتخزين**:
  - تصدير كامل بيانات المكتبة (الكتب، النسخ، الطلاب، الإعارات، الحجوزات، سجل التدقيق) بضغطة زر كملف `wathba_database_snapshot.json`.
  - إمكانية استعادة البيانات بضغطة زر عند الحاجة.

## 2. خطوات استعادة قاعدة البيانات (Restore Procedure)

في حال حدوث أي طارئ أو رغبة في استرجاع نقطة زمنية سابقة:

1. **الاستعادة عبر pg_restore:**
```bash
pg_restore --clean --if-exists --no-owner \
  -d "postgresql://postgres:[YOUR-PASSWORD]@db.[PROJECT-REF].supabase.co:5432/postgres" \
  wathba_backup_YYYYMMDD_HHMMSS.dump
```

2. **الاستعادة الفورية من الواجهة:**
- التوجه إلى: **لوحة الإدارة -> الإعدادات -> النسخ الاحتياطي**.
- الضغط على **استيراد نسخة احتياطية** واختيار ملف JSON.
- يقوم النظام بالتحقق من سلامة الجداول واستعادة البيانات فوراً.

---

## 3. حماية وتخزين صور فحص الكتب وأغلفتها (Supabase Storage)
- يتم إنشاء باكت (Bucket) باسم `wathba-library-media` مع مجلدين:
  - `covers/`: لحفظ صور أغلفة الكتب.
  - `condition-photos/`: لحفظ صور فحص الكتب وتوثيق التلف.
- لا يتم حذف أي صورة توثيقية سابقة حتى تظل كل حالة محفوظة تاريخياً.
