# مكتبة وثبة الذكية | WATHBA SMART LIBRARY
## المنصة الإلكترونية الشاملة لإدارة مكتبة فريق وثبة

منصة متكاملة واحترافية لإدارة المكتبة المدرسية لفريق وثبة، صُممت بالكامل باللغة العربية مع دعم RTL فائق الدقة، ونظام باركود وQR مستقل لكل نسخة كتاب ولكل طالب، مع قاعدة بيانات مركزية مبنية على PostgreSQL وSupabase ونظام فحص وتوثيق وحماية الكتب بالصور.

---

## 🌟 الميزات والخصائص الأساسية

1. **نظام QR والباركود الذكي**:
   - رمز QR مستقل لكل نسخة ورقية (مع الفصل التام بين عنوان الكتاب ونسخه الورقية `WTH-125-001` إلى `WTH-125-005`).
   - رمز QR مشفر وآمن لكل طالب بدون معلومات شخصية مكشوفة.
   - شاشة «المسح الذكي» للمشرف تدعم كاميرا الهواتف والحواسب والإدخال اليدوي السريع.
   - توليد وطباعة ملصقات الـ QR الفردية والجماعية وبطاقات عضوية الطلاب.

2. **طريقتا تسليم الكتب المعتمدة**:
   - **الاستلام المباشر (Direct Checkout)**: فحص QR الطالب والنسخة مع التحقق من حد الكتابين وغياب المتأخرات.
   - **التوزيع الجماعي (Bulk Distribution)**: فرز الطلاب حسب الصف والمجموعة وتوليد كشوف التوزيع وتسجيل الاستلام الفعلي.

3. **حماية وتوثيق حالة الكتب (رف الإرجاع والفحص)**:
   - تصوير حالة الغلاف والصفحات قبل التسليم وعند الاسترجاع.
   - انتقال الكتب المسترجعة إلى «رف الإرجاع» لحين فحصها واعتمادها من المشرف.
   - حفظ السجل التاريخي لصور وتقارير الفحص السابقة دون حذف.

4. **نظام الدخول فائق البساطة للطلاب**:
   - لا بريد إلكتروني، لا أرقام هواتف، ولا كلمات مرور معقدة.
   - دخول الطالب باسمه ورمز PIN مكون من 4 أرقام أو بمسح بطاقته الذكية.
   - خصوصية تامة: لا يطلع الطالب على بيانات زملائه.

5. **لوحات تحكم متخصصة**:
   - **بوابة الطالب**: كتبي، حجز الكتب، بطاقة إنجاز القراءة، تحدي فرسان وثبة الشهري، كتاب الأسبوع.
   - **لوحة المشرف**: المسح الذكي، التسليم والاسترجاع، متابعة المتأخرات، رف الإرجاع.
   - **لوحة الإدارة**: 11 مؤشر قياس أداء، رسوم بيانية تفاعلية، إدارة الكتب والنسخ، شؤون الطلاب، إدارة الطاقم، الجرد الدوري، والتقارير.

6. **10 تقارير إدارية متخصصة**:
   - تقارير شاملة قابلة للتصدير الفوري إلى **Excel (XLSX)**، **PDF**، و**الطباعة المباشرة** بتنسيق RTL عربي فخم.

7. **نظام الجرد الميداني (Inventory System)**:
   - إنشاء جلسات جرد ومسح الرفوف ومقارنتها تلقائياً بقاعدة البيانات لتمييز الموجود والمستعار والمفقود.

## 🛠️ التقنيات المعتمدة

- **الواجهة الأمامية**: React 18, TypeScript, Tailwind CSS, Lucide Icons.
- **إدارة الخدمات والخادم**: Supabase (Client + Row Level Security + Storage).
- **قاعدة البيانات**: PostgreSQL 15+ مع مشغلات قيود الإعارة الصارمة (Triggers & Functions).
- **محركات الباركود والطباعة**: QRCode Generator, jsPDF, XLSX (SheetJS), Html5Qrcode.
- **التوقيت الرسمي**: آسيا/الرياض (`Asia/Riyadh`).

## 🚀 طريقة التشغيل والتشغيل المحلي

### 1. تثبيت الحزم:
```bash
npm install
```

### 2. إعداد الاتصال السحابي (Supabase):
- أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
- افتح **SQL Editor** ونفذ الملفات بالترتيب:
  1. `supabase/migrations/001_initial_schema.sql` (إنشاء الجداول والسياسات ومشغلات التحقق).
  2. `supabase/migrations/002_seed_data.sql` (إدراج بيانات البداية والكتب والتصنيفات والطلاب).
  3. `supabase/functions/rpc_loan_operations.sql` (الدوال المخزنة للإعارة والاسترجاع الذري).
- انسخ رابط المشروع والمفتاح وضعهم في ملف `.env`:
```env
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_STORAGE_MODE=supabase
```

*(ملاحظة: تدعم المنصة أيضاً وضع التشغيل الذاتي `VITE_STORAGE_MODE=local` لتعمل فوراً حتى دون اتصال خارجي).*

### 3. تشغيل خادم التطوير:
```bash
npm run dev
```
